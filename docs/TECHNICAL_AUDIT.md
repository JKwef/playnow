# Технический аудит Quaeso

Дата актуализации: 13 ноября 2026 года. Состояние локального рабочего дерева;
результаты прежних этапов не считаются проверками текущего коммита.

## Вывод

Реализован основной путь: Steam-вход, импорт и обогащение библиотеки, фильтры,
ручные игры, подбор, история, принятый выбор, откладывание и удаление аккаунта.
Есть демо и добровольная синхронизация выбора и сроков откладывания.
Архитектура поддерживаемая, локальные проверки клиента проходят. Готовность
к публичному выпуску требует проверки подписанных сборок и серверного окружения.

## Архитектура

- Expo SDK 58, React Native 0.88.1, React 19.3, строгий TypeScript.
- React Navigation: native stack и нижние вкладки; Expo Router не используется.
- Zustand хранит состояние сессии и синхронизации; TanStack Query — серверные данные.
- Supabase Auth/Postgres с RLS и четыре Edge Functions на Deno.
- Steam OpenID и Steam Web API; RAWG для метаданных.
- SecureStore для мобильных токенов, localStorage для веб-сессии, AsyncStorage
  для данных устройства с ключами аккаунта.
- `src/features/` разделяет функции продукта, `src/shared/` — общие компоненты
  и сервисы. Сервисы принимают зависимости для изолированных тестов.

Steam ID для авторизации берётся из `app_metadata`, серверные секреты остаются
в Edge Functions. Публичный Supabase key в конфигурации клиента сам по себе
не является секретом; изоляция данных зависит от серверной проверки и RLS.

## Исправлено при актуализации

### Сохранение мобильной сессии

Прежняя запись удаляла старую сессию до сохранения новой. Теперь части нового
значения записываются в неактивный слот, после чего переключается manifest.
Ошибка записи частей или manifest сохраняет прежнее значение. Старый формат
с числовым счётчиком читается и заменяется только после успешной записи.

Операции одного ключа сериализуются между экземплярами хранилища с общим driver.
Счётчики слотов позволяют удалить части, оставшиеся после прерывания записи.
Очистка старого слота после успешного переключения не превращает успешное
сохранение в ошибку. Размер частей ограничен байтами UTF-8; символы Unicode
не разрываются. Добавлены регрессионные тесты ошибок, миграции, конкуренции,
Unicode, пустого значения и очистки незавершённого слота.

Ограничение: SecureStore не предоставляет транзакцию над несколькими ключами.
Схема опирается на успешную запись отдельного manifest; физическое повреждение
хранилища и отзыв refresh token сервером она не устраняет. Перезапуск приложения
и обновление токенов нужно дополнительно проверить на устройствах.
Документация: [SecureStore SDK 58](https://docs.expo.dev/versions/v58.0.0/sdk/securestore/).

### Воспроизводимость CI и локальное окружение

Supabase CLI в database job закреплён на опубликованной версии `2.122.1`
вместо `latest`. Это устраняет неявный переход на CLI v3; соответствие этой
версии полному database job ещё должен подтвердить GitHub Actions.
Основание: [несовместимые изменения CLI v3](https://supabase.com/changelog/supabase-cli-v3).

В Windows доступен Node.js 24.22.1, но npm отсутствовал в PATH. Локально установлен
npm 11.6.2, зависимости восстановлены через `npm ci` без изменения lock-файла.
`scripts/dev-env.ps1` настраивает PATH текущего PowerShell, использует локальный
кэш и при необходимости скачивает закреплённый npm с проверкой SHA-256.
Системный PATH не меняется; `.tools/`, `.npm-cache/` и `node_modules/` исключены из Git.
Скрипт отключает телеметрию Expo в текущей консоли, чтобы CLI не пытался
записать идентификатор в недоступную из sandbox папку профиля пользователя.

## Выполненные проверки

Дополнительная проверка пользовательского пути: запущен Metro на порту 8081,
через интерфейс воспроизведён и исправлен возврат из демо после перезагрузки.
Web export и браузерный smoke прошли в 4/4 вариантах (320/390 px, обе темы),
включая библиотеку, подбор, восстановление принятого выбора без сети и историю.
Данные и сессии синтетические, обращения в настоящий Supabase заблокированы.
Подробности: `docs/qa/UI_MANUAL_2026-11-13.md`.

- `npm ci --no-audit --no-fund` — установлено 1329 пакетов из lock-файла.
- `npm run typecheck` — прошли проверки приложения и тестов.
- `npm run lint` — прошёл без замечаний.
- `npm run format:check` — прошёл.
- `npm run test:ci` — 48 наборов, 355 тестов, все прошли.
- `npm run check:mobile-config` — прошёл; EAS-проект ещё не привязан.
- `expo install --check` с `EXPO_OFFLINE=1` — локальная карта SDK не выявила
  несовместимости. Это не проверка актуальных версий через сеть.

В текущей проверке не запускались Deno, локальная база/Docker, GitHub Actions,
облачные EAS-сборки и сценарии на физических устройствах. Не проверялись
развёрнутые миграции, серверные секреты и настоящий Steam-вход. Исторические
числа 117 Jest/36 Deno из прежнего аудита не являются текущими результатами.

   смену аккаунта и удаление. Получить зелёный CI на выпускаемом коммите.
2. **P1: физические Android/iOS.** Проверить подписанные сборки, возврат из браузера,
   фон/перезапуск, оффлайн, обновление токенов и синхронизацию двух устройств.
   Подготовленная матрица: `docs/research/STAGE7_DEVICE_CHECKLIST.md`;
   открытые условия сборки: `docs/STAGE9_ACCEPTANCE.md`.
3. **P2: полезность продукта.** Провести реальные пользовательские сессии по протоколу
   этапа 7. Наличие алгоритма и unit-тестов не доказывает качество рекомендаций.
4. **P2: сопровождение зависимостей.** При установке npm выдал предупреждения
   о deprecated-пакетах, включая ESLint и транзитивные glob. Нужен отдельный
   разбор совместимых обновлений; автоматическая смена версий вне SDK не выполнялась.

Автоматические исправления не заменяют физическую приёмку. Деплой, публикация
и коммит в рамках этой актуализации не выполнялись.
