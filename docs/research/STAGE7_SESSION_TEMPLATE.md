# Бланк исследовательской сессии этапа 7

Незаполненный шаблон. Создать закрытую копию для каждого участника.
Пустое поле означает «нет данных», число 0 — реально измеренный ноль.

## Условия сессии

| Поле                                                         | Значение |
| ------------------------------------------------------------ | -------- |
| Код участника и дата                                         |          |
| Модератор                                                    |          |
| Версия, commit, незакоммиченные изменения                    |          |
| Тестовое окружение и серверная версия                        |          |
| Устройство, ОС, браузер, размер экрана                       |          |
| Тема, масштаб шрифта, вспомогательные технологии             |          |
| Размер библиотеки диапазоном; открыта ли игровая информация  |          |
| Опыт Quaeso; привычный способ выбора                         |          |
| Согласие на заметки / запись / цитирование отдельно          |          |
| Ответственный, доступ, срок удаления, способ отзыва согласия |          |
| Порядок инструментов T2 и T3                                 |          |

Не записывать Steam ID, пароль, токен и полную библиотеку. Контакт для согласованного
повторного визита хранить отдельно от бланка.
