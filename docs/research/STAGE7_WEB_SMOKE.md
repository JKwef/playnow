# Веб проверка перед сессиями этапа 7

Скрипт `scripts/stage7-web-smoke.mjs` проверяет экспортированную веб-сборку
в изолированных браузерных контекстах на 320/390 px в двух темах. Все внешние
запросы перехватываются: ответы приложения подменяются тестовыми, остальные
внешние запросы блокируются. Учётные записи синтетические, к реальному серверу
скрипт не обращается. Это проверка интерфейса, а не исследовательская сессия.

## Запуск

Нужны зависимости проекта, Node.js, доступный модуль Playwright и Chromium
либо установленный браузер, поддерживаемый Playwright. Скрипт не устанавливает
инструменты автоматически. Можно использовать модуль Playwright из среды
разработки через `PLAYWRIGHT_MODULE` — абсолютный путь к каталогу пакета.
Параметры запуска браузера: [документация Playwright](https://playwright.dev/docs/library).

```powershell
npx expo export --platform web --output-dir .tools/stage7-web
# Если Playwright не разрешается из зависимостей проекта:
$env:PLAYWRIGHT_MODULE = 'C:\path\to\node_modules\playwright'
# Для установленного Microsoft Edge; иначе используется Chromium Playwright:
$env:PLAYWRIGHT_CHANNEL = 'msedge'
npm run test:web:stage7
```

Если модуль уже доступен, `PLAYWRIGHT_MODULE` не задавать. Для Chromium с
браузером Playwright удалить `PLAYWRIGHT_CHANNEL` из окружения. Другой каталог
экспорта передаётся как `npm run test:web:stage7 -- путь/к/экспорту`.
Сборка должна использовать Supabase URL из `app.json`; не подставлять другой
сервер через переменные окружения при экспорте для этой проверки.

## Что проверяется

- Демо принимает примерную игру без записи библиотеки/принятого выбора аккаунта.
- Переходы между вкладками сохраняют поиск и режим.
- Основное действие видно в окне; горизонтального переполнения страницы нет.
- Принятие настоящей карточки из тестового набора сохраняется после загрузки
  страницы заново; при недоступном API остаются библиотека и принятый выбор.
- При подмене тестового аккаунта принятый выбор первого не показывается.
- В ходе сценария нет необработанных ошибок страницы.

Скриншоты и `summary.json` записываются в игнорируемый каталог
`.tools/stage7-qa`. Отчёт содержит явную отметку
`synthetic-browser-smoke-only`.
Отчёт также содержит версию браузера и SHA-256 экспортированных JS-бандлов,
чтобы связывать результаты с конкретной сборкой.

Ошибка сценария даёт ненулевой код выхода
и скриншот с окончанием `failure.png`. Перед новым запуском скриншоты могут
перезаписываться; сохранять нужный комплект отдельно с версией сборки.

Скрипт не подтверждает реальный Steam-вход, работу RLS, серверное удаление,
физические Android/iOS, системный шрифт, экранный диктор или пользу для людей.
Эти проверки выполняются по [матрице устройств](STAGE7_DEVICE_CHECKLIST.md)
и [исследовательскому протоколу](STAGE7_PROTOCOL.md).
