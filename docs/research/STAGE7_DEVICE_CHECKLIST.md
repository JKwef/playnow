# Этап 7 Проверка готовности на устройствах

Создать копию матрицы на каждую проверяемую сборку. Пока стоит «Не проверено»,
критерий не закрыт. Для каждой ячейки записывать: пройдено / ошибка с кодом /
не проверено / неприменимо с объяснением. Веб-проверка с подменой API учитывается
отдельно от реальных Steam-входа, базы и физических устройств.

## Паспорт проверки

Версия приложения и commit: ______. Незакоммиченные изменения: ______.
Идентификатор сборки или URL веба: ______. Дата и проверяющий: ______.
Тестовое окружение, миграции и версии серверных функций: ______.
Android — модель и версия ОС: ______. iOS — модель и версия ОС: ______.
Веб — ОС, браузер и версия: ______. Аккаунты A/B — только обезличенные коды.

Тесты смены и удаления аккаунта проводить на выделенных тестовых аккаунтах,
которые можно потерять. Снимки не должны содержать токены, пароли, Steam ID
и полные личные библиотеки. Реальное каскадное удаление проверяет владелец
тестового окружения; успешное исчезновение экрана само его не доказывает.

## Карточка ошибки

| Поле                                                               | Значение |
| ------------------------------------------------------------------ | -------- |
| Код и связанный пункт Dxx / наблюдение Pxx-Tx                      |          |
| Версия, устройство, тема, шрифт, состояние сети                    |          |
| Условия и шаги воспроизведения                                     |          |
| Ожидаемое / фактическое поведение                                  |          |
| Частота воспроизведения и обезличенное свидетельство               |          |
| Критичность и влияние на принятие решения                          |          |
| Ответственный, исправление, повторная проверка на той же платформе |          |
| Статус                                                             | Открыта  |

Блокирующие ошибки: смешение или потеря данных, сломанный вход/удаление,
неверное применение исключений, невозможность принять/восстановить выбор,
недоступное основное действие или отсутствие доступного выхода из ошибки.
При падении основного сценария сессию остановить, сохранить наблюдение и
повторить после исправления. Косметические замечания не скрывают эти блокеры.

## Условия завершения

Перед выпуском все применимые строки должны иметь подтверждение, открытых
блокирующих ошибок этапов 1–6 быть не должно. Непроверенная среда означает
отсутствие решения о готовности для неё. Проверку реального сервера и зелёный CI
подтвердить отдельно: старый локальный прогон или успешный мок их не заменяет.

Для веб-проверки на синтетических данных см. [инструкцию запуска](STAGE7_WEB_SMOKE.md).
