# Чего не хватает Quaeso

Срез на 23 ноября 2026 года. Приоритет учитывает влияние на игрока и результаты ручной проверки. Нумерация показывает предлагаемый порядок работ.

| Приоритет | Сценарий                                              | Что доступно сейчас                                                                                                                                                                                  | Что должно получиться                                                                                                                                                                         |
| --------- | ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1         | Вернуть доступ к аккаунту по почте                    | В форме входа можно ввести пароль. Вошедший пользователь может задать новый пароль в настройках. На экране входа нет действия для забытого пароля.                                                   | Игрок запрашивает письмо, задаёт новый пароль и входит с ним.                                                                                                                                 |
| 1         | Удалить аккаунт, зарегистрированный только по почте   | Самостоятельное удаление в приложении доступно Steam-пользователю. Для входа по почте инструкция отправляет в поддержку, адрес которой в материалах релиза помечен как временный.                    | Игрок подтверждает удаление из своего профиля. При невозможности войти доступен проверенный канал поддержки.                                                                                  |

Отдельно решить, нужен ли перенос избранного между устройствами.                        |

Для этапа 8 ТЗ также допускает использование причин отказа в ранжировании и автоматическое определение установки на игровом ПК. Сейчас причины доступны в истории, а отметку установки ставит сам игрок. Для ранжирования ТЗ предусматривает отдельное продуктовое решение, для определения установки нужен проверенный источник. Это возможные расширения после проверки спроса.
