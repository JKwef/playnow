## Подтверждённый дефект

### UI-01 · P2 · Возврат из демо не работает после обновления страницы

Шаги:

1. Открыть `/login`.
2. Нажать «Попробовать без входа».
3. Обновить страницу `/demo` средствами браузера.
4. Нажать «Вернуться ко входу в Steam».

Ожидание: открывается `/login`.

Факт: остаётся `/demo`, интерфейс не меняется. Стрелка возврата в заголовке после обновления также отсутствует. Повторено несколькими нажатиями, в том числе после возврата к обычному размеру окна. Без обновления страницы та же кнопка успешно возвращает на `/login`.

Влияние: после обновления или открытия демо без предыдущего экрана в стеке пользователь не может перейти ко входу предусмотренной для этого кнопкой.

Источник: `src/features/demo/screens/DemoScreen.tsx:45` — обработчик вызывает `navigation.goBack()` без альтернативного перехода при пустой истории стека. Рекомендуется добавить переход к Login, если возврат невозможен. Исправление не выполнялось.

Доказательство: [скриншот после безрезультатного нажатия](demo-return-after-reload.png). Само отсутствие перехода подтверждено также неизменным URL и деревом интерфейса до/после нажатий.
