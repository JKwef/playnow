# Политика конфиденциальности PlayNow

Дата вступления в силу: 2 ноября 2026 г.

PlayNow помогает выбрать игру из вашей библиотеки Steam. Здесь описано, какие данные приложение
использует, где они хранятся и как их удалить.

## Какие данные мы получаем

- **Steam ID** (публичный 17-значный номер аккаунта). Его сообщает Steam после входа.
  Пароль от Steam приложение не видит: вход проходит на сайте Steam.
- **Список ваших игр из Steam**: номер игры (appid), название, сколько часов вы играли,
  когда запускали последний раз.
- **Игры, которые вы добавили вручную**.
- **Жанры и обложки игр**. Их приложение находит по названию игры в открытых базах
  RAWG и магазина Steam.

Мы не собираем email, имя, контакты, геолокацию, рекламные идентификаторы и не используем
аналитику или рекламу.

## Где хранятся данные

- **На сервере (Supabase)**: Steam ID и список игр. Доступ к записям есть только у вашего
  аккаунта (правила Row Level Security в базе данных).
- **На вашем устройстве**:
  - токены входа лежат в защищённом хранилище системы (Keychain на iOS, Keystore на Android);
  - копия списка игр нужна для работы без интернета;
  - список отложенных игр.

## Кому передаются данные

- **Steam (Valve)**: по вашему Steam ID запрашивается список игр.
- **RAWG**: передаются только названия игр, чтобы найти их жанры и обложки.
  Ваш Steam ID в RAWG не отправляется.
- **Supabase**: хостинг базы данных и серверных функций.

Ключи доступа к Steam и RAWG хранятся только на сервере и в приложение не попадают.
Данные не продаются и не передаются третьим лицам для рекламы.

## Как удалить данные

- Кнопка **«Выйти из аккаунта»** в настройках удаляет с устройства сессию и копию списка игр.
- Чтобы удалить данные с сервера, создайте запрос в
  [разделе Issues репозитория](https://github.com/JKwef/playnow/issues) с темой
  «Удаление данных». Мы удалим ваш Steam ID и список игр в течение 30 дней.

## Изменения политики

Если политика изменится, новая версия появится на этой странице с новой датой вступления в силу.
