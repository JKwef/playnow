# Этап 5: принятие и сохранение выбора

## Реализация

Основное действие результата «Выбираю эту игру» сохраняет appid и название,
контекст, режим, состояние жанрового фильтра и время принятия. Сначала
подтверждается запись на устройство, затем показывается успех. Ошибка записи
сохраняет прежнее решение и допускает повтор. Отмена возвращает предыдущий
принятый выбор, а после первого принятия удаляет его; ошибка отмены также
допускает повтор. Отмена доступна в текущей сессии приложения.

Ключ `playnow:acceptedChoice:v1:<steamId>` принадлежит аккаунту на текущем
устройстве. Восстановление и запись используют очередь `accountScope`;
смена аккаунта сбрасывает память, поздние операции не подменяют карточку.
Удаление аккаунта очищает ключ общим механизмом, сохраняя тему устройства.
Ошибка чтения блокирует перезапись неизвестного сохранённого решения до
успешного повтора. Просмотр и перебор рекомендаций не записывают этот ключ.

Главный экран показывает последнее принятое решение с действиями «Открыть»
и «Подобрать другое». Если игра исчезла из доступной библиотеки, карточка
сохраняет название и критерии, объясняет отсутствие и предлагает новый подбор.
Пока библиотека недоступна, отдельно обозначается сохранённый снимок выбора.

Открытие отделено от принятия: на телефоне используется HTTPS-страница Steam,
в браузере на ПК предлагается ссылка локальному клиенту Steam с запасной
страницей в браузере. Копирование ссылки доступно отдельно; при отказе буфера
остаётся выделяемый URL. Сбой открытия не означает автоматически отсутствие
Steam и не меняет выбор. Успех означает лишь передачу ссылки системе. Ручные
игры без Steam appid можно принять; отсутствие ссылки объясняется явно.

## Проверки

Автотесты охватывают восстановление новым экземпляром хранилища, отмену с
возвратом прежней игры, ручные игры, сбои чтения/записи/отмены, повтор,
параллельное нажатие, поздние чтения и записи другого аккаунта и удаление
аккаунта с сохранением темы. Экранные проверки подтверждают независимость
перебора и открытия от принятого решения, карточку удалённой игры, смену
аккаунта, запасной путь после сбоя открытия и отказ копирования.

Команды: `npm run typecheck`, `npm run lint`, `npm run format:check`,
`npm run test:coverage`, `npx expo export --platform web`.

Проверка 13 ноября 2026: успешно пройдены 37 наборов, 265 клиентских тестов,
типизация приложения и тестов, lint, форматирование и веб-экспорт Expo.
Покрытие строк собираемых для покрытия модулей — 96,13%, ветвей — 88,17%.

## Выпуск и ограничения

Миграция Supabase и изменение серверных функций на этом этапе не нужны.
Прежние условия развёртывания этапов 1–4 сохраняются. Новая зависимость
`expo-clipboard` установлена через Expo CLI для SDK 58; собственные сборки
нужно пересобрать с этим модулем. На устройстве используется обычное локальное
хранилище без обещания синхронизации или удалённого запуска ПК.

Физические Android/iOS и реальный переход в установленный клиент Steam
требуют отдельной проверки на устройствах. Веб-сборка и автоматические
подмены внешних API не заменяют эту проверку.
