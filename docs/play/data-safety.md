# Data safety: готовые ответы для Play Console

Заполняйте по этому файлу раздел **App content → Data safety**. Ниже — что приложение
реально делает (по коду), как это отображается в форме и что писать в примечаниях.

## Итоговые ответы (верхний уровень формы)

| Вопрос Play Console                                        | Ответ   | Почему                                               |
| ---------------------------------------------------------- | ------- | ---------------------------------------------------- |
| Собирает или передаёт приложение обязательные типы данных? | **Да**  | Steam ID и список игр нужны для работы               |
| Все передаваемые данные шифруются при передаче?            | **Да**  | Только HTTPS/TLS: Supabase, Steam, RAWG              |
| Есть способ запросить удаление данных?                     | **Да**  | «Настройки» → «Удалить аккаунт» + публичная страница |
| Продаются ли данные?                                       | **Нет** | Нет монетизации данных                               |
| Используется ли реклама или трекинг?                       | **Нет** | Нет рекламных и аналитических SDK                    |
| Есть ли независимый аудит безопасности?                    | **Нет** | Не требуется для MVP                                 |

## Какие данные собираются

| Категория в Play Console                        | Конкретные данные                                                                 | Обязательно            | Назначение                                   | Кому передаются                                                                                                   |
| ----------------------------------------------- | --------------------------------------------------------------------------------- | ---------------------- | -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Personal info → **User IDs**                    | Steam ID (публичный 17-значный номер аккаунта Steam)                              | Да, без него нет входа | App functionality (вход и импорт библиотеки) | Steam (Valve) — чтобы получить список игр; Supabase — хостинг (обработчик)                                        |
| App activity → **Other actions**                | Список игр: appid, название, время в игре, дата последнего запуска                | Да                     | App functionality (бэклог и подбор)          | Steam (Valve) — источник списка; RAWG — только названия игр для жанров и обложек; Supabase — хостинг (обработчик) |
| App activity → **Other user-generated content** | Игры, которые пользователь добавил вручную: название, необязательный appid, жанры | Нет, по желанию        | App functionality (ручные игры в подборе)    | RAWG — только названия; Supabase — хостинг (обработчик)                                                           |

Больше ничего не собирается:

- нет email, имени, телефона, адреса, даты рождения;
- нет геолокации, контактов, календаря, SMS, звонков;
- нет фото, видео, аудио, файлов;
- нет идентификаторов устройства и рекламных ID;
- нет истории браузера и установленных приложений.

## Передача третьим лицам

Play считает «передачей» отправку данных сторонним сервисам. Учитывайте:

| Получатель        | Что получает                               | Зачем                                                    | Ссылка на политику                                  |
| ----------------- | ------------------------------------------ | -------------------------------------------------------- | --------------------------------------------------- |
| **Steam (Valve)** | Steam ID (через официальный Steam Web API) | Получить публичную библиотеку игр                        | <https://store.steampowered.com/privacy_agreement/> |
| **RAWG**          | Только названия игр, без Steam ID          | Определить жанры и обложки                               | <https://rawg.io/privacy>                           |
| **Supabase**      | Steam ID, список игр, ручные игры          | Хостинг базы данных и Edge Functions (обработчик данных) | <https://supabase.com/privacy>                      |

Данные **не продаются**, не передаются брокерам данных и не используются для рекламы.
Supabase работает как обработчик по поручению разработчика, а не как независимый получатель.

## Безопасность

- **Шифрование при передаче:** да, HTTPS/TLS для всех запросов.
- **Хранение на устройстве:** токены входа — в защищённом хранилище ОС (Keychain/Keystore);
  кэш списка игр — в AsyncStorage без токенов.
- **Доступ на сервере:** строки таблиц закрыты Row Level Security — пользователь видит только
  свои записи; ключ service role есть только внутри Edge Functions.
- **Шифрование при хранении:** обеспечивается провайдером Supabase (encryption at rest).

## Удаление данных

- В приложении: **Настройки → Удалить аккаунт** (подтверждение, удаление сразу).
- Публичная страница: `https://jkwef.github.io/playnow/account-deletion.html` — этот адрес
  указывается в поле **Delete account URL**.
- Удаляются: Steam ID, список игр, ручные игры, история запусков, локальная сессия и кэш.
- Сроки: сразу при удалении в приложении; резервные копии — до 30 дней.
- Альтернатива: запрос на support@playnow.app (placeholder) в течение 30 дней.

Удаление доступно **без переустановки приложения** и без обращения в поддержку. На вопрос
о частичном удалении отвечайте «Нет»: приложение удаляет аккаунт целиком, отдельного
удаления отдельных игр по запросу сейчас нет.

## Разрешения

Приложение не запрашивает опасных разрешений Android:

- нужно только сетевое соединение (INTERNET);
- нет доступа к геолокации, камере, микрофону, контактам, SMS, звонкам, внешнему хранилищу;
- нет `QUERY_ALL_PACKAGES`: для открытия Steam используется обычный deep link `steam://run/<appid>`,
  а не сканирование установленных приложений.

## Реклама, аналитика, сторонние SDK

- Рекламных сетей нет.
- Аналитики и crash-репортинга нет.
- Сторонние SDK: Supabase JS (сеть/данные), Expo (фреймворк). Рекламных и трекинговых нет.
- Файлы cookie не используются (мобильное приложение).

## Возрастная аудитория

Приложение не предназначено для детей младше 13 лет: это инструмент для владельцев
Steam-аккаунтов. В Play Console выберите целевую аудиторию 13+ и не публикуйте в
программе «Семьи».
